# PR.3 Collection Manipulator:

## Overview:

The **Student Data Organizer** is a menu-driven Python application designed to manage student information through a command-line interface.

The application allows users to add, display, update, and delete student records, as well as search for students based on the subjects they study.

This project demonstrates fundamental Python concepts and data structures.

## Features:

- **Add Student:** Add student details such as ID, name, age, grade, date of birth, and subjects.
- **Display All Students:** View all stored student records.
- **Update Student Information:** Modify student details using their student ID.
- **Delete Student:** Remove a student record using their student ID.
- **Search Students by Subject:** Find students enrolled in a specific subject.
- **Exit:** Terminate the application.

## Concepts Implemented:
- Lists
- Dictionaries
- Sets
- Tuples
- Loops and conditional statements
- `match-case` statements
- User input handling

## Student Information:
The program stores the following details:
- Student ID
- Student Name
- Student Age
- Student Grade
- Student Date of Birth
- Student Subjects
